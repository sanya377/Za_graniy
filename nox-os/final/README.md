# Чужой телефон / NOX OS

Мобильный детективный хоррор 16+. Лиза Волкова исчезла, оставив телефон на остановке. Внутри лежат её фотографии, копии переписок и маршрут к станции № 4. Игрок проверяет версии и решает, кому передать запись и как вывести Лизу к берегу.

В первом сеансе нажмите «Поднять телефон». «Дело Лизы» показывает текущие версии, источники и восстановленную хронологию. Осматривайте метаданные снимков, ищите страницы во встроенном браузере и сопоставляйте их с заметками, перепиской и журналом звонков. Подсказки доступны внутри проверок. Сохранение локальное, на устройстве и в текущем браузере.

## Запуск

```sh
npm run dev
```

Откройте `http://localhost:4173/`. Страница использует ES-модули, поэтому для локального запуска нужен статический HTTP-сервер. Команда запуска использует только Node.js и не требует установки зависимостей. На GitHub Pages запуск и сборка не требуются.

## Публикация на GitHub Pages

1. Скопируйте папку в `nox-os/final/` в корне публикуемой ветки.
2. В репозитории `sanya377/Za_graniy` GitHub Pages уже публикует `main` из корня. Для другого репозитория выберите **Settings → Pages → Deploy from a branch** и соответствующую ветку с папкой **/(root)**.
3. После успешного запуска Pages откройте [игру](https://sanya377.github.io/Za_graniy/nox-os/final/).

Для игры не нужны учётная запись, сервер приложений, внешние медиа и API. Озвучка звонков синтезирована и хранится вместе с проектом. Звонки и кассета сопровождаются расшифровками.

## Состав проекта

| Файл или папка | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | Мобильный интерфейс и приложения |
| `engine.js` | Состояние кампании, условия переходов, последствия и очередь событий |
| `story.js` | Реплики, фото, документы, проверки и концовки |
| `assets/` | 25 фотографий, увеличенный фрагмент, обои, эффекты и записи звонков |
| `SCENARIO.md` | Карта сюжета и зависимостей со спойлерами |
| `tests/` | Проверки движка, сквозные сценарии Playwright, локальный сервер и генератор сигналов |
| `TESTING.md` | Результаты и ограничения проверки |

## Механики

- Пять глав открываются по результатам расследования. Решения и найденные источники запускают события без ожидания таймера.
- Восемь приложений, 127 сюжетных сообщений, 25 снимков со сведениями о захвате, два входящих звонка с голосовой почтой и записи ночной смены.
- Двенадцать проверок, включая хронологию, сопоставление журналов, акростих, последовательность звуков и восстановление маршрута. Архив открывается двумя независимыми способами.
- Реплики с последствиями, отзыв сообщения, скрытая улика в затемнённом кадре и четыре концовки. Отношения с Антоном влияют на возможность отвлечь Ильина.
- Сохранение текущего экрана, открытых материалов, прочтения, решений, прогресса проверок и очереди звонков. Новая игра запускается с рабочего стола или из эпилога.
- Экран блокировки, домашний экран, безопасные зоны, системная клавиатура и отключение звуковых эффектов. Вибрация используется, если браузер предоставляет API.

## Повторная проверка

```sh
npm test
npm ci
npx playwright install --with-deps webkit
npm run test:browser
```

По умолчанию сквозной сценарий использует WebKit и профиль iPhone 13. Для Chromium установите браузер Playwright и запустите `NOX_BROWSER=chromium npm run test:browser`. Для проверки опубликованной версии передайте адрес с завершающей косой чертой через `NOX_URL`.
